# GitHub Copilot + MLflow AI Gateway

Route the [GitHub Copilot CLI](https://github.com/github/copilot-cli) through the MLflow AI Gateway to get centralized tracing and observability, while each developer authenticates with their own GitHub Copilot subscription.

## Prerequisites

- MLflow server running with a SQL backend (`mlflow server --port 5000`)
- GitHub Copilot CLI installed (`npm install -g @github/copilot`)
- An active GitHub Copilot subscription

## Step 1: Create a GitHub Copilot Endpoint

Navigate to the **AI Gateway** tab at `http://localhost:5000/#/gateway` and create a new endpoint. Select **GitHub Copilot** (`github-copilot`) as the provider and name the endpoint `github-copilot` — you can change the name, but make sure to use the same name in the next step.

The endpoint defaults to the Copilot API base `https://api.githubcopilot.com`. For GitHub Enterprise, use `https://api.enterprise.githubcopilot.com`.

## Step 2: Configure Environment Variables

Set the following environment variable so the Copilot CLI routes through the gateway and uses your endpoint:

```bash
export COPILOT_API_URL="http://localhost:5000/gateway/proxy/github-copilot"
```

### Alternative: VS Code's built-in Copilot Chat

Copilot Chat in VS Code ignores `COPILOT_API_URL`. Point it at the gateway with this **User** setting instead:

```json
{
  "github.copilot.advanced.debug.overrideCapiUrl": "http://localhost:5000/gateway/proxy/github-copilot"
}
```

It must be set in User settings — VS Code ignores this setting at workspace scope, so a repository cannot silently redirect your Copilot traffic.

:::warning
This is an internal debug setting. It is not documented by GitHub and may change or be removed in any release.
:::

## Step 3: Run GitHub Copilot

```bash
copilot
```

The Copilot CLI authenticates using your existing GitHub Copilot credentials and all requests are proxied through the gateway. The gateway recognizes the client by its `User-Agent` (`copilot-linux-x64/1.0.75` for the CLI, `GitHubCopilotChat/0.32.1` for VS Code) and forwards your own short-lived bearer token upstream, so **usage is billed to your individual GitHub account** rather than to a central organization API key.

## What You Get

Every conversation is captured as an MLflow trace. Open the **Logs** tab in the MLflow UI to inspect inputs, outputs, token usage, and latency for every request.

The provider is OpenAI-compatible, so the endpoint serves `/chat/completions` and `/embeddings`, as well as `/responses` (OpenAI Responses shape) and `/v1/messages` (Anthropic Messages shape). It is also reachable through the typed OpenAI passthrough at `http://localhost:5000/gateway/openai/v1/chat/completions`.

:::warning
The Copilot API host `api.githubcopilot.com` is **not an officially documented public API**. It is the internal endpoint used by GitHub's own Copilot clients and may change without notice.
:::

:::note
[GitHub Models](https://docs.github.com/en/github-models) is a different GitHub product with its own API, model naming, and authentication. This provider targets the Copilot API and should not be used to reach GitHub Models.
:::
